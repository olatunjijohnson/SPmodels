SPmodels in WebR

SPmodels is an R package for spatial modelling in research and teaching. This page hosts its prebuilt WebAssembly package repository for browser-based R.

Install in a WebR session

After your page has initialized WebR, install SPmodels and load it like this:

await webR.installPackages("SPmodels", {
  repos: "https://olatunjijohnson.github.io/SPmodels/"
});
await webR.evalRVoid("library(SPmodels)");

The install URL is this site's root. The repository index is at src/contrib/PACKAGES; WebR locates it automatically from the root URL.
